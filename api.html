Welcome to Kiwi Finance API

Build powerful applications with our comprehensive REST API. Kiwi Finance provides a modern, secure, and scalable platform for your development needs.

Key Features

Our API offers enterprise-grade features designed for modern applications:

  • 🚀 RESTful Architecture - Clean, predictable URL structure
  • 🔒 Secure by Default - OAuth 2.0 and API key authentication
  • ⚡ High Performance - Sub-100ms response times
  • 📊 Real-time Updates - WebSocket support for live data
  • 🌍 Global CDN - Low latency worldwide

Base URL

ENDPOINT 
https://api.nectaros.com/v1

Quick Example

Here's a simple example to get you started:

cURL 
curl -X GET "https://api.nectaros.com/v1/users" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"

Authentication

Kiwi Finance API uses API keys to authenticate requests. You can view and manage your API keys in the Dashboard.

API Key Authentication

Include your API key in the Authorization header:

Header 
Authorization: Bearer YOUR_API_KEY

OAuth 2.0

For user-based authentication, we support OAuth 2.0 flow:

JavaScript 
const response = await fetch('https://api.nectaros.com/v1/oauth/token', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    grant_type: 'authorization_code',
    client_id: 'YOUR_CLIENT_ID',
    client_secret: 'YOUR_CLIENT_SECRET',
    code: 'AUTHORIZATION_CODE'
  })
});

Quick Start Guide

Get up and running with Kiwi Finance API in minutes.

Step 1: Get Your API Key

Sign up for an account and generate your API key from the dashboard.

Step 2: Install SDK (Optional)

Bash 
npm install @nectaros/sdk
Bash 
pip install nectaros
Bash 
composer require nectaros/sdk

Step 3: Make Your First Request

JavaScript 
import NectarOS from '@nectaros/sdk';

const client = new NectarOS('YOUR_API_KEY');

// Get all users
const users = await client.users.list();
console.log(users);

List Users Active

Retrieve a paginated list of all users in your organization.

Endpoint 
GET /users

Query Parameters

Parameter Type Description
page integer Page number (default: 1)
limit integer Items per page (default: 10, max: 100)
sort string Sort field (created_at, name, email)

Response Example

JSON 
{
  "data": [
    {
      "id": "usr_123456",
      "name": "John Doe",
      "email": "john@example.com",
      "created_at": "2024-01-15T10:30:00Z",
      "status": "active"
    }
  ],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 150,
    "pages": 15
  }
}

Try It Out

Create User

Create a new user in your organization.

Endpoint 
POST /users

Request Body

Field Type Description
name Required string User's full name
email Required string User's email address
role string User role (admin, user, viewer)

Request Example

cURL 
curl -X POST "https://api.nectaros.com/v1/users" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Jane Smith",
    "email": "jane@example.com",
    "role": "user"
  }'

Update User

Update an existing user's information.

Endpoint 
PUT /users/{id}

Path Parameters

Parameter Type Description
id Required string User ID

Delete User

Permanently delete a user from your organization.

Endpoint 
DELETE /users/{id}

⚠️ Warning: This action cannot be undone. All user data will be permanently deleted.

Webhooks

Receive real-time notifications when events occur in your Kiwi Finance account.

Available Events

  • user.created - New user created
  • user.updated - User information updated
  • user.deleted - User deleted
  • payment.completed - Payment processed successfully

Webhook Payload

JSON 
{
  "event": "user.created",
  "timestamp": "2024-01-15T10:30:00Z",
  "data": {
    "id": "usr_123456",
    "name": "John Doe",
    "email": "john@example.com"
  }
}

Error Codes

Kiwi Finance API uses conventional HTTP response codes to indicate success or failure.

Code Status Description
200 OK Request successful
201 Created Resource created successfully
400 Bad Request Invalid request parameters
401 Unauthorized Invalid or missing API key
404 Not Found Resource not found
429 Too Many Requests Rate limit exceeded
500 Internal Server Error Server error - try again later

Rate Limits

API rate limits help maintain platform stability and ensure fair usage for all users.

Default Limits

Plan Requests/Hour Requests/Day
Free 100 1,000
Pro 1,000 10,000
Enterprise 10,000 Unlimited

Rate Limit Headers

Each API response includes headers with rate limit information:

  • X-RateLimit-Limit - Maximum requests per hour
  • X-RateLimit-Remaining - Remaining requests
  • X-RateLimit-Reset - Time when limit resets (Unix timestamp)
